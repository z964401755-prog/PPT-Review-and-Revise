## 🚀 PPT 协同审阅工作台 v1.1.0 更新日志

### ✨ 核心功能与 UI 升级
- **网页端协同卡片集成**：将「网页端协同与一键分享」专属卡片整合至左侧任务栏，支持一键上传 PPT/PPTX 文件与实时复制协同审阅链接。
- **全界面亮色/暗色自适应**：深度适配日间（Light Mode）与夜间（Dark Mode）双主题，优化侧边栏、工具栏及 PPT 舞台视窗在浅色模式下的色彩对比度与文字清晰度。
- **顶栏 UI 布局精简**：清理顶部工具栏中重复的侧边栏折叠控制按钮，布局更加紧凑直观。
- **协同批注与体验优化**：优化幻灯片缩略图切换逻辑与纯净观感模式的浮层响应体验。
